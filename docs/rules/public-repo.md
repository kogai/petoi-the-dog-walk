# 公開リポジトリでの注意

このリポジトリは公開されている。コミットした内容は、あとで消しても履歴・フォーク・キャッシュに残る前提で扱う。

## 1. コミットしてはいけないもの

| 種類 | 例 |
|---|---|
| 秘密情報 | API キー、トークン、パスワード、`.env` |
| ローカル環境の状況 | ホームディレクトリのパス（`/Users/<名前>/`、`/home/<名前>/`）、PC 名・ユーザー名、シリアルポート名（`/dev/cu.<機器名>`）、ローカルの設定ファイル（`.claude/settings.local.json` など） |
| ネットワークの情報 | IP アドレス（プライベートも含む）、Wi-Fi の SSID、MAC アドレス |
| 機器・個人の識別情報 | シリアル番号、Bluetooth の機器名、メールアドレス、写真・動画に写った部屋や人 |
| 実験の生データ | 上のどれかを含むログ。貼る前に伏せる |

伏せるときは `<IP>`、`<PORT>`、`<HOME>` のようにプレースホルダーに置き換える。

## 2. 仕組みで防ぐ

- `.gitignore` でローカルのファイル（`.env`、`*.local.*`、実験の出力など）を除外している。
- `scripts/check-public.sh` が、追跡中のファイルからホームのパス・IP アドレス・シリアルポート名・メールアドレスなどを探し、見つかれば失敗する。`scripts/check.sh` と CI から実行される。
- 誤検知を許可するときは、その行に `public-ok` と書き、PR で理由を説明する。

## 3. コミットの前に

- `git diff --staged` を読んで、上の表に当てはまるものが無いことを確かめる。`git add -A` の前に `git status` で対象を確認する。
- 実験結果を貼るときは、出力を1行ずつ確認して伏せてからコミットする。
- 入れてしまったら、push する前なら `git commit --amend` などで取り除く。push した後なら、すぐに人に知らせる（秘密情報は無効化が先。履歴を消すだけでは足りない）。
