## 表記の区別

すべての文書で、記述を次の3種類に区別する。

- **確認済み**: 公式ドキュメントまたはコードを読んで確認した事実。[design/facts.md](design/facts.md) に ID と出典を付けて置く
- **設計案**: この計画での決め事（実装前・未実行）
- **未確認 / 実験**: 実機や API で試して確かめる項目（実験 ID `E00` などを付ける）
