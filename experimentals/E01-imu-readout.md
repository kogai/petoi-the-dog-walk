# E01: 標準ファームで IMU の値を PC から読めるか

- 状態: 依頼中
- 依頼日: 2026-09-25
- 実施日:
- 実施者:

## 目的

基板上の IMU（MPU6050、F-B2）の値を、標準ファームのまま Mac から読めるかを確かめる。
読めれば、転倒・持ち上げの検知（D-01 安全上の例外、D-02 反射の対象）と、Jev に渡す `situation` に使える。

## 必要なもの

- 機材: Bittle（標準ファーム）、シリアル経路（USB / Bluetooth）。Wi-Fi 経路しか無い場合は「実施できない」と書いて終了してよい
- ソフトウェア: E00 と同じ
- 所要時間の目安: 30分

## 安全上の注意

- 手で持ち上げる・傾ける操作をするので、事前に `d` を送ってサーボを止めておく。
- `g`（手順6）を送るとサーボが動き出すことがある。手順6は床に置いた状態で行い、終わったら `d` を送る。

## 手順

1. E00 の手順 A と同じ方法でシリアルモニターに接続する。
2. [Serial Protocol](https://docs.petoi.com/apis/serial-protocol.md) を見て、IMU の値を表示するトークンを探す。
   （このリポジトリではまだ確認していない。候補として `v` があるが **未確認**。見つけたトークンを記録する）
3. 見つけたトークンを送り、表示を記録する。
4. Bittle を次の姿勢にして、それぞれで 3 を繰り返す。
   - 平らな床に置いた状態
   - 右に 45 度くらい傾けた状態
   - 手で持ち上げた状態
   - 裏返した状態
5. 連続で表示させる方法があれば、1秒あたり何回くらい値が出るかを記録する。
6. 床に置いた状態で、`g`（IMU 切替、F-T1）を送る前後で、表示や挙動が変わるかを記録する。
   終わったら、もう一度 `g` を送って元に戻し、`d` を送る。

## 記録すること

- [ ] 環境（ファームのバージョン、接続手段、Mac の OS / Node.js のバージョン）
- [ ] IMU 表示に使ったトークンと、その出典（ドキュメントのどこか）
- [ ] 各姿勢での出力（そのまま貼る）
- [ ] 値の意味が分かれば、その説明（角度か、加速度か、単位）
- [ ] 連続表示の可否と頻度
- [ ] `g` の前後の違い

## 判定基準

| 結果 | 設計への影響 |
|---|---|
| 姿勢ごとに値が区別できる | `sensing` に IMU を入れる。D-01（転倒時の安全例外）を検討できる |
| 1回ずつなら読める | 理性層の `situation` には使える。反射層（100ms）には頻度が足りるか別途判断 |
| 読めない | ファームの改造が必要。D-01・D-02 の候補から IMU を外す |
