## 共通の注意

- 実機を動かすときは、Bittle を平らな床か台の上に置き、落ちない・ぶつからない場所で行う。
- 動作がおかしいときは、停止トークン `d` を送るか電源を切る。
- **このリポジトリは公開されている。** 結果を貼る前に、API キー・IP アドレス・シリアルポート名（`/dev/cu.<機器名>`）・PC 名・ユーザー名・ホームのパス・シリアル番号を `<IP>`、`<PORT>` のように伏せる（[public-repo.md](../docs/rules/public-repo.md)）。
- 実験用のスクリプトや出力ファイルは、このフォルダの中に置いてもコミットされない（`.gitignore`）。結果は `.md` に伏せてから貼る。
- 実行したコマンドと、出力をそのまま貼る（要約だけにしない）。
